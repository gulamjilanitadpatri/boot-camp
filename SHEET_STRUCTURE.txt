PYTHON BOOT CAMP — GOOGLE SHEET STRUCTURE

Create these EXACT sheet tabs:

1) Registration
A1 Timestamp
B1 Name
C1 Email
D1 Mobile
E1 Roll
F1 Department
G1 Year
H1 Division
I1 College
J1 Password

2) Admin
A1 Timestamp
B1 Email
C1 Password
D1 Name

Add one admin row, for example:
A2 = current date/time
B2 = your admin email
C2 = your admin password
D2 = Admin

3) AptitudeTests
A1 TestID
B1 TestName
C1 Description
D1 DurationMinutes
E1 MarksPerQuestion
F1 StartDate
G1 EndDate
H1 Status
I1 CreatedAt

4) AptitudeQuestions
A1 QuestionID
B1 TestID
C1 Question
D1 OptionA
E1 OptionB
F1 OptionC
G1 OptionD
H1 CorrectAnswer
I1 Marks

5) TestResults
A1 Timestamp
B1 ResultID
C1 TestID
D1 TestName
E1 StudentEmail
F1 StudentName
G1 TotalQuestions
H1 Attempted
I1 Correct
J1 Wrong
K1 Score
L1 MaxScore
M1 Percentage
N1 TimeTaken

6) Attendance
A1 Timestamp
B1 Date
C1 StudentEmail
D1 StudentName
E1 Status

NOTES:
- Do not rename the headers.
- Keep headers in row 1.
- The website creates Test 1, Test 2, Test 3… through the Admin dashboard.
- Students can submit each test only once.
- Marks are calculated on the server and saved in TestResults.
